# face_crops/

- **Contents:** 1,599 face crops (PNG), the crops used in the manuscript's analysis (359 same-tracklet pairs and 494 different-face pairs). They were added after the supervisor's permission, as reported by the researcher on 27-11-2026.
- **The faces are identifiable.** Cropping does not anonymize a face, and no anonymization was applied.
- **Filenames** `crop_0001.png` … `crop_1599.png` were assigned in a seeded random order. The original filenames encode the video frame number, so they were not used. No mapping to the original files, frames, timestamps, tracklets or pairs is included.
- **Copies:** byte-identical to the original crops. Checksums are in `SHA256.txt`.
- **Not usable for recomputing the paper's statistics:** pair lists and landmarks are not included.
- **No consent record** exists for the source footage. Do not use these images for any purpose other than the research context of the manuscript.
